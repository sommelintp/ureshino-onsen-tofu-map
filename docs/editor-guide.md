# 編集者ガイド（市職員・観光協会・旅館組合の担当者向け）

このマップのデータは **Google スプレッドシート** が正本です。シートを編集すると、サイトは次に開かれたときから新しい内容を表示します。
GitHub の操作は必要ありません。

## 1. 編集を始めるには

1. 管理者からスプレッドシート「[嬉野温泉 湯どうふマップ データ](https://docs.google.com/spreadsheets/d/1BlTnAfIig9Zj76Qv0a5tHG7JfKfjU4yrGzZ0DLq9zTo/edit)」の **編集権限** をもらう（Google アカウントのメールアドレスを伝える）
2. シート `places` を開く。1行が1つの施設です
3. 変更したら保存は自動。サイトを再読み込みして反映を確認する

> 編集した内容はスプレッドシートの「変更履歴」（ファイル → 変更履歴）で誰がいつ変えたか分かり、元に戻せます。

## 2. 列の意味

## 3. よくある作業

**価格が変わった**: メニュー列の該当行の価格と備考（確認年月）を直す → 最終更新日を今日にする。

**新しい店を載せる**: 最終行に追加。名称・種別・住所・提供形態・メニュー・出典を入れる。座標が分からなければ空のまま（一覧には出ますが地図には出ません）。管理者が `npm run geocode` を実行するか、Google マップで座標を調べて入れると地図に出ます。

**閉店・休業**: 公開状態を `非公開` に。編集メモに理由と日付。削除はしない（履歴のため）。

**一般の方からの投稿**: GitHub の Issue（「追加提案」「修正提案」ラベル）や Google フォームの回答シートを確認し、出典を確かめてから `places` に反映。反映したら Issue を閉じる（GitHub は管理者に頼んでもよい）。

**年次の見直し**: 年に1回、価格・営業時間・定休日を各店の公式情報で確認し、最終更新日を更新する。

## 3.5 非公開にしたい行・メモがある場合（公開用タブ）

サイトはシートを「リンクを知っている全員が閲覧可」で読むため、**シートの中身は編集メモや非公開行も含めて誰でも見られます**。
投稿者の連絡先や内部事情は書かないでください。閉店情報など「非公開」の行も見られたくない場合は、公開用タブを分けます。

1. タブ `公開` を作り、A1 に次の式を入れる（`places` タブから「非公開」以外の行だけを出す）
   `=FILTER(places!A:AQ, places!E:E<>"非公開")`
2. 管理者に `config.js` の `SHEET_NAME` を `公開` にしてもらう
3. 編集は今までどおり `places` タブで行う（`公開` タブは自動で追従）

## 3.6 入力の自己点検（GitHub 不要）

サイトの URL の末尾に `?check=1` を付けて開くと、画面下にデータの **エラー**（座標が市外、URL の形式、出典なし など）と
**注意**（座標なし、id なし、メニューなし）が一覧で出ます。シートを編集した後の確認に使ってください。
例: `https://sommelintp.github.io/ureshino-onsen-tofu-map/?check=1`

## 4. ルール

- 出典のない情報は `要確認` までにとどめる（出典が付いたら `公開`）
- 口コミ本文の転載はしない。評価は数値のみ
- 投稿者の個人情報（連絡先など）はシートに書かない。編集メモにも残さない
- 写真は権利者の許諾があるもののみ

## 5. 困ったとき

- サイトに反映されない: シートの共有設定が「リンクを知っている全員（閲覧者）」になっているか、`config.js` の `SHEET_ID` が正しいか管理者に確認。ブラウザのコンソールにエラーが出ます
- 行が消えた・壊れた: ファイル → 変更履歴 から復元
- 検証エラー（自動スナップショットが失敗する）: GitHub Actions のログに「どの行の何が不正か」が出ます（例: 座標が嬉野市周辺ではない、URL が http で始まらない）
