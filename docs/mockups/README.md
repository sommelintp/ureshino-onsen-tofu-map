# ビジュアル全面リデザイン — HTML モック

テーマは「湯けむりと、とろける白」。写真を主役にしながら、嬉野茶の深緑、土鍋の茶、温かい和紙色で地域性を出す。

## 画面

- `top.html`: トップ。没入型ヒーロー、目的別導線、SNS投稿、地図、読み物。
- `list.html`: 一覧。検索・フィルター、結果カード、地図の二分割。
- `detail.html`: 詳細。写真／投稿、価格、メニュー、使用豆腐・温泉、出典。
- `mobile.html`: 幅390pxを基準にしたスマホ。下部固定タブとボトムシート。
- `index.html`: 上記4画面への入口。

各画面右下の月アイコンでライト／ダークを切り替えられる。`?theme=dark` / `?theme=light` でも固定できる。

## モック用データと画像

- `mock-data.js` の投稿URLはレイアウト確認専用のダミー。`data/media.json` は変更していない。
- `hero-yudofu.png` はモック専用に生成した写真調ビジュアル。実装段階では、確認済みSNS投稿がある場合は公式埋め込みを優先し、空の場合のフォールバック候補として扱う。
- 店名・価格などは既存データの表示例。データ形式・値は変更していない。

## 実装段階で引き継ぐ要点

- 初回表示はヒーローと地図に限定し、SNS埋め込みはIntersectionObserverで遅延ロード。
- 投稿のない店は和紙色＋湯気モチーフのプレースホルダーへ自動切替。
- モバイル詳細はボトムシート、主要操作は下部固定タブに集約。
- `prefers-reduced-motion` ではアニメーションを停止。
