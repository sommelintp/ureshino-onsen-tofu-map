## 依頼文（ここから下をコピー）

まず git pull で最新にしてから作業してください。
AGENTS.md と docs/ARCHITECTURE.md を読み、あなたはフロントエンド担当として作業してください。

### やってほしいこと
【例: トップページのヒーローを、温泉湯どうふの動画が全画面で流れるデザインにしてほしい】

### 目的・見せたい印象
【例: 初めて見た人が「とろける湯どうふを食べに行きたい」と思うこと。上品で、温泉街の空気感】

### 参考にしたいもの（任意）
【例: 星野リゾートのサイトの写真の使い方 / https://... 】

### 使うデータ
- データは window.TofuData から取る（docs/ARCHITECTURE.md の「データ API」）。data/ と js/schema.js と js/data.js は編集しない
- 足りないデータ項目があれば、作業を止めずに仮の値で画面を作り、最後に「バックエンドへの依頼」として何が欲しいかを書いて報告する

### 守ること
- 既存機能（絞り込み・検索・詳細・共有URL・投稿フォーム・位置修正・現在地・?check=1・Google マップ）を壊さない
- スマホ幅 390px で横スクロールなし、コンソールエラーなし
- 外部ライブラリはバージョン固定＋SRI（npm の実ファイルから算出）
- 写真・動画は公式埋め込みのみ（画像の保存・転載は禁止）

### 出してほしいもの
- ブランチ codex/【作業名】で作業し、push して PR を作る（main に直接 push しない）
- PR に PC とスマホのスクリーンショット（ライト／ダーク）、変更点、既存機能の確認チェックリスト
- 「バックエンドへの依頼」があれば PR 本文の最後に箇条書き
